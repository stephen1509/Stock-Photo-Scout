# Dreamstime Rules

Dreamstime is the first intended marketplace, but this checkpoint makes no automated claim of compliance.

- Treat marketplace rules as changeable external requirements.
- Confirm requirements from Dreamstime's current authoritative guidance before implementing validation or preparing a submission.
- Do not hard-code speculative limits, categories, keyword counts, release rules, or acceptance criteria.
- Keep submissions and uploads manual unless separately authorized.
- A future preflight should show evidence and warnings, never silently claim acceptance.

Checkpoint 0.01 has no Dreamstime account access, upload, scraping, or API use.
